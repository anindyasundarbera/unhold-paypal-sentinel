# UX Profile

Generated by `setup-ui-ux-skills`. All UI/UX skills in this project read this file before changing layout, copy, or interaction.

## Aesthetic reference

- **Standard:** Stripe
- **Notes:** A dark product UI whose main surface is data tables, so clarity and trust come first. Tokens already live in `public/index.html` (`--bg #0d1117`, `--panel #161b22`, `--line #30363d`, `--accent #58a6ff`, status colours, 4px spacing scale). AG Grid (Quartz theme, tuned to those tokens) renders every table. Keep borders at 1px, panels solid, one accent colour, and let the grids carry the page.

## Banned anti-aesthetics

- Gratuitous glassmorphism / `backdrop-filter` without a high-contrast boundary
- Floating pastel pill badges for ordinary metadata. Pills are only for status that changes (ready, waiting, failed, healthy). Plain facts such as carrier, mode or date are plain text.
- Arbitrary decorative gradients and neon glowing borders
- Multi-color radial rainbow gradients on standard CTAs. One solid accent for the primary action.
- Cartoon empty-state illustrations. Empty grids say in one sentence what to do next.
- Nested scrollbars and icon bloat inside inputs. A grid scrolls in its own box; the page must not scroll a second time inside it.

## Accessibility target

- **Level:** WCAG 2.1 AA
- **Contrast:** Normal text above 4.5:1, large text and borders above 3:1. Muted text is `#9aa4af` on `#0d1117`, which clears 4.5:1.
- **Touch / focus:** 44x44px targets on touch devices (the cockpit raises buttons to 44px on coarse pointers). Visible 2px accent focus ring on every control. Dialogs trap and restore focus.

## Brand tone and microcopy voice

- **Voice:** Utilitarian & Minimal
- **Capitalization:** Sentence case for UI copy and buttons
- **Notes:** The product moves money, so copy is precise and calm: say what will happen, how many parcels and how much money, and what cannot be undone. Verb-first buttons ("Approve plan", "Upload 3 parcels"). Errors say what failed and what to do next, never blame the user.

## Icon library

- **Library:** Lucide
- **Package / path:** none installed yet (`lucide` for plain SVG when icons are added)
- **Notes:** The cockpit is text-only today: status is shown with labelled chips and no icons or emoji. If icons are added, use Lucide only, outline at 16px, never emoji.

## Agent rules

1. Read this profile before creating or editing any UI, CSS, or microcopy.
2. Prefer skills by task: new page → `page-patterns` (name the pattern before markup); layout / chrome → `viewports`; forms → `forms`; overlays → `surfaces`; loaders → `loaders`; empty views → `empty-states`; motion → `motion`. Before finishing UI, run `ux-audit`.
3. Use only the recorded icon library (or project SVG path). Do not mix icon sets or use emoji as UI icons.
4. Never introduce items on the banned list.
5. Destructive actions always use an explicit confirmation dialog.
6. Every data table is an AG Grid. Role homes, queues and approvals reuse the shared grid theme in `public/app.js`.
